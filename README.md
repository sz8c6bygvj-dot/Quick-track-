# QuickTrack

A lightweight browser-based task and milestone tracker built with HTML, CSS, and JavaScript. Data is saved locally in the browser using `localStorage`.

## Features
- Add and delete tasks or milestones
- Mark items as completed
- Filter by **All**, **Active**, or **Completed**
- Automatic local browser storage persistence

## Live Demo
Once GitHub Pages is enabled, view the app at:
`https://yourusername.github.io/your-repo-name/`
